# Addie Enterprises HTML v4.2 — Deal Analyzer

## New features
- Live Buy / Negotiate / Pass recommendation
- Maximum buy price based on target ROI
- Opportunity score
- Estimated platform fees
- Projected profit and ROI breakdown
- Comprehensive mid-to-high-end brand dropdown
- Other Brand option for brands not listed
- iPad and mobile responsive layout

## Brand list
The dropdown includes a broad selection of luxury, premium, contemporary, and accessible-luxury brands used for handbags, wallets, luggage, and accessories. It also includes Other for anything not listed.

## Upload
1. Upload every file in this ZIP to the root of the GitHub repository.
2. Replace matching files.
3. Commit with:
   `v4.2 - Add deal analyzer and brand dropdown`
4. Wait 2–3 minutes for GitHub Pages.
5. Refresh or open the site in a new Private Safari tab.
