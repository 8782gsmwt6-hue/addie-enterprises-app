UPLOAD TO GITHUB
1. Open the repository that hosts the current Addie Enterprises app.
2. Replace the existing files with every file from this folder.
3. Commit the changes.
4. Wait 1–3 minutes, then reload the GitHub Pages site.
5. On iPhone/iPad, close the old browser tab and reopen the site. If an old Home Screen app still appears, remove it and add it to the Home Screen again.

Important: Export a backup from the current app before replacing files.
