# Addie Enterprises HTML v4.4.1 — Size Field

## New field
Adds a dedicated `Size` field to:
- Add/Edit Item
- Deal Analyzer
- Search
- Inventory display
- Deal-to-inventory transfer

## Examples
- Neverfull: MM
- Speedy: 30
- Alma: BB
- Kelly: 28
- Shoes: 38
- Belt: 95 cm

## Existing data
Existing inventory remains compatible. Older items simply have a blank Size field until edited or imported.

## Upload
1. Upload every file in this ZIP to the GitHub repository root.
2. Replace matching files.
3. Commit:
   `v4.4.1 - Add size field`
4. Wait 2–3 minutes and refresh.

No Firebase rule changes are required.
