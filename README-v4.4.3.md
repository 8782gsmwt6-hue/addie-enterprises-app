# Addie Enterprises HTML v4.4.3 — ROI Begins When Listed

## New accounting treatment

### Purchased and not listed
- Counts as inventory investment.
- Does not calculate projected profit.
- Does not calculate ROI.
- Displays `—` for ROI.
- Does not reduce Combined ROI.

### Listed
- Listing price is used for projected profit.
- Purchase investment is included in projected ROI.

### Sold
- Actual sale price and actual fee are used.
- Profit and ROI are treated as actual.

## Dashboard updates
- Purchased / Unlisted count
- Listed count
- Unlisted Inventory Cost
- Listed Inventory Cost
- Projected Profit for listed items only
- Combined ROI excluding purchased items that have not been listed
