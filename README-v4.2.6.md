# Addie Enterprises HTML v4.2.6 — Multi-Platform Toggle Fix

## Fix
Replaces the unreliable iPad checkbox control with independent tap-to-toggle buttons.

## How it works
1. Tap eBay — it stays highlighted.
2. Tap Poshmark — it also stays highlighted.
3. Both platforms are saved to Firebase.
4. Tap either platform again to deselect it.
5. Select Other to enter a custom platform name.

## Upload
1. Upload every file in this ZIP to the root of the GitHub repository.
2. Replace matching files.
3. Commit with:
   `v4.2.6 - Fix multi-platform selection`
4. Wait 2–3 minutes.
5. Refresh the site.
6. Open an item and select eBay and Poshmark together.
