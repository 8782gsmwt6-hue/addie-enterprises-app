# Addie Enterprises App

Mobile-first inventory, sales, and profit tracker.

## Features
- Add, edit, delete, search, and filter items
- Track purchase price, fees, repairs, shipping, and other costs
- Track listing and sale details
- Automatic total invested, net proceeds, profit, margin, and ROI calculations
- Business dashboard and profit trend
- Export/import backup
- CSV export
- Offline use after first load
- Dark mode

## Publish
Upload all files individually to the repository root, then:

1. Open repository Settings.
2. Open Pages.
3. Choose Deploy from a branch.
4. Select main and /(root).
5. Save.
6. Open the live site in Safari.
7. Tap Share → Add to Home Screen.

Data is stored locally on the device. Export backups regularly.
