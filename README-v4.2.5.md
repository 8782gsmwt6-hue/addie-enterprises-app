# Addie Enterprises HTML v4.2.5 — Custom Other Values

## New behavior
Whenever Other is selected, a free-text field appears.

Supported:
- Other Brand
- Other Category
- Other Expected Sale Platform
- Other Listed On platform(s)
- Other Actual Sale Platform

For multiple custom listing platforms, separate names with commas.

The typed value is saved to Firebase instead of the generic word `Other`.

## Upload
1. Upload every file in this ZIP to the root of the GitHub repository.
2. Replace matching files.
3. Commit with:
   `v4.2.5 - Add custom Other fields`
4. Wait 2–3 minutes.
5. Refresh the site.
6. Test by selecting Other under Brand, Category, or a platform field.
