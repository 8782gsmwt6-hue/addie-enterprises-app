# Addie Enterprises HTML v4.4.4 — Dashboard Item Click

## New behavior
Tap any inventory item in the Dashboard table.

The app will:
1. Open the Items tab.
2. Find the matching inventory record.
3. Scroll directly to it.
4. Highlight it briefly in gold.

## Scope
This is a small navigation-only update.

It does not:
- Change Firebase data
- Change calculations
- Change inventory records
- Add new filters
- Change security rules

## Upload
1. Upload every file in this ZIP to the GitHub repository root.
2. Replace matching files.
3. Commit:
   `v4.4.4 - Open dashboard items in Items tab`
4. Wait 2–3 minutes and refresh.

No Firebase rule changes are required.
