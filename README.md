## Deploy

1. Open the repository in GitHub.
2. Upload all files from this package directly to the repository root.
3. Commit the changes.
4. Open the Actions tab and wait for a green `pages build and deployment` check.
5. Open the GitHub Pages website in Safari.
6. Refresh the page or append `?v=3` to the site address if Safari displays an older cached version.

## iPhone ChatGPT button

The button copies the full resale-analysis prompt and opens `https://chatgpt.com/`. iOS may open the installed ChatGPT app. Paste the copied prompt into a new conversation and send it.

A normal website cannot reliably inject and automatically submit a complete prompt inside another iPhone app, so copy-and-open is the dependable workflow.
