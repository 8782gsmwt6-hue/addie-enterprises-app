# Addie Enterprises HTML v4.3.2 — Deal Analyzer Tab

## New workflow
- Deal Analyzer now has its own main tab.
- Add/Edit Item is reserved for purchased inventory.
- Addie can evaluate an item without saving it.
- Add This Deal to Inventory transfers the analysis into a blank inventory form.
- Clear resets the potential purchase.

## Upload
1. Upload every file to the GitHub repository root.
2. Replace matching files.
3. Commit:
   `v4.3.2 - Move Deal Analyzer to its own tab`
4. Wait 2–3 minutes and refresh.

No Firebase changes are required.
