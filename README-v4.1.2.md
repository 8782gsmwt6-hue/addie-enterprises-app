# Addie Enterprises HTML v4.1.2

This corrects the incomplete v4.1 inventory workflow update.

## Visible features
- Inventory Number field
- Automatic AE-0001 numbering for new items
- Favorite / Priority field
- Expanded workflow statuses
- Days held in the Items view
- Profitability rating badge
- Inventory number and favorite displayed in tables
- Improved search

## Existing item
Your existing item is preserved. It may show as Unnumbered until edited and saved.
New items receive an automatic inventory number.

## Upload
1. Upload every file to the root of the GitHub repository.
2. Replace matching files.
3. Commit with:
   `v4.1.2 - Show inventory workflow features`
4. Wait 2–3 minutes and refresh.
