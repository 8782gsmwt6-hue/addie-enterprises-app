# Addie Enterprises HTML v4.1 — Inventory Workflow

## New features
- Automatic inventory numbers: AE-0001, AE-0002, etc.
- Favorites that sort to the top
- Expanded inventory workflow statuses
- Search by inventory number, color/material, authentication, source, and notes
- Sort by purchase date, profit, brand, and status
- Days held for every item
- Green / yellow / red profitability rating
- Dashboard metrics for average days held and favorites

## Upload
1. Upload every file in this ZIP to the root of the GitHub repository.
2. Replace matching files.
3. Commit with:
   `v4.1 - Add inventory workflow`
4. Wait 2–3 minutes for GitHub Pages.
5. Open the site in a new Private Safari tab for the first test.

## Notes
Existing Firebase inventory is preserved.
Older items without inventory numbers will continue to work. New items receive an automatic number when saved.
